# Calcolo Vetrate

Web app per il calcolo di vetrate fisse e scorrevoli organizzate per cantiere:
lati e vani con nome, parametri di detrazione per cantiere, pianta e prospetti,
distinta e ordine vetri. Funziona offline e si installa nella schermata Home.

I dati restano salvati sul dispositivo di chi la usa; i cantieri si scambiano
con Esporta / Importa cantiere. Istruzioni d'uso in `LEGGIMI.txt`.
